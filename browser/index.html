YOUR WORLD, IN ONE BROWSER
Following
Keep creators and projects close. Independent, local-first, and built into Noxviola.

 

 

 

  
  
  
  
  
  
 

 
GitHub projects: public releases and current Git tags. GitHub creators: public owned repositories and their latest reported activity. These are periodic snapshots, not a complete history: intermediate changes, deleted tags and private activity may be missed. Modrinth project links collect public per-version metadata, not project-level compatibility aggregates; changelogs and files are not downloaded. Other HTTPS sources are saved for manual checking, not automatically scraped. Checks use GitHub’s public API without your website cookies; no assets are downloaded or executed. Rate/access failures stay visible.
