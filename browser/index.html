Local spelling
Right-click a marked word for corrections. This choice applies across identities and is excluded from appearance presets. On Windows and Linux, the engine can download dictionaries from Chromium's CDN even when checking is off; this switch does not block those downloads. macOS uses its system spellchecker.

  
Keyboard shortcuts
Use combinations such as Ctrl+Shift+K, CmdOrCtrl+L or F8. Leave a shortcut empty to disable it. Each active combination must be unique.
