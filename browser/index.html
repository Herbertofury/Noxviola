Downloads
Choose a destination, then control each transfer.

 
Downloaded files are never opened automatically. This transfer list lasts for the current browser run; restart-resume is not implemented.





 
Site permissions
Decisions are scoped to the requesting site, embedding site and browser identity.

 
Camera and microphone permissions are separate. Unknown permissions, screen capture and native device access remain blocked until their dedicated controls are implemented. Revoking a decision prevents future permission checks; close the page to stop an already active capture.
