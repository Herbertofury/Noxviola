# Noxviola browser

Read `.agents/foundry/AGENTS-adapter.md` for the pinned shared engineering core. This repository is now the owner's public browser home. The assistant backlog is maintained on the single [Assistant-Backlog wiki page](https://github.com/Herbertofury/Noxviola/wiki/Assistant%E2%80%90Backlog); historical index files stay preserved until verified consolidation permits cleanup.

- `npm test` checks durable state and vault logic; `npm run check` checks syntax; `npm start` launches the experimental Electron browser. Native runtime tests remain separate.
- Enderloom is the behavioral/source baseline; preserve provenance, GPL notices and its source repository. Ferrum feature wishes inform requirements, not a bulky runtime import.
- Local-first personal vault is a prime feature. Never publish vault/profile/session data, credentials, private fixtures or raw conversation histories. Do not silently scrape/download media or sync user content.
- Favor Rust where real whole-workload evidence supports it. Do not misrepresent Chromium/WebView2 as pure Rust or claim mainstream parity/speed without tests.
- Keep theme/customization modules optional and accessible. Purple fox is a future original mascot; Firefox-inspired styling does not authorize copying trademark assets.
- Preserve all project requests, acceptance gates, pauses and accountability history. Held PR #4 and unrelated denied operations are not authorized by this conversion; do not repackage them through another route.
- No permanent deletion, credential grants, security-setting changes or unlicensed asset reuse is implied.
