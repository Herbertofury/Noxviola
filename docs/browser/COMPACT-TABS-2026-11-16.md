# Compact Windows chrome and tab search — 2026-11-16

Source revision `3aa984ba393bde9576b814b3d945ad967c67935a` includes the compact two-row browser chrome, native Windows caption controls, unified tab surfaces, same-origin favicon loading, and the configurable tab-search window. Revision `f530f0fe3a6d04564c21c33446b6dc846fcff7be` adds a native tab-search regression without changing the application code. The existing input-method fix from `1ef3575` was preserved during integration.

The search window filters open tabs by title, URL, identity, workspace, and group, and can activate or close an open tab or restore a tab closed in the current process. Its button can be placed before or after tabs; its rows can be detailed or compact. Those choices persist in preferences and appearance presets. Recently closed tabs in this implementation are held in memory and do not survive a browser restart. The window is sandboxed, accepts commands only from its own main frame, and does not contact a third-party tab-search service.

Local Windows tests exercised the packaged executable's search, close, restore and tab activation against synthetic local webpages, and a native keyboard event opened the search using the default shortcut. A separate source-app test changed placement and row style and confirmed both after restart. The native browser gate at `run-5MAC2A` tested the real dropdown and passed two launches; it also covered selecting the next tab when workspaces have interleaved entries. The favicon loader uses only the current page's origin, anonymously; if the site advertises a cross-origin icon, it tries the origin's conventional `/favicon.ico` and otherwise shows a generic globe. Some icon formats and cross-origin-only icons remain unsupported. The Windows title bar has native caption buttons; physical drag and Windows snap behavior have not been comprehensively qualified. Firefox/Chrome/Edge/Opera feature parity and universal extension support remain ongoing work.
