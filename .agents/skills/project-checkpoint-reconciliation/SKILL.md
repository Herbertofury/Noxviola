# Reconcile a public project checkpoint

Read AGENTS.md, README.md, TODO.md and DECISIONS.md. Read the relevant accountability/retrospective section only for the project being updated. This is an index maintenance task, not authorization to change every linked project.

## Establish current evidence and ownership

Follow the item's canonical repository/issue/PR/checkpoint and inspect current state before carrying forward an old claim. Check active work to avoid duplicate owners. Distinguish an intended plan, local implementation, passing tests, merged source, published artifacts and native user acceptance. A new commit or closed issue alone does not prove all acceptance gates passed.

For each changed item retain a concise result, exact evidence link, unresolved gate and next useful action. A failed or not-run check remains visible. Preserve valid progress when an unrelated dependency is blocked. Treat historical source links as provenance, not automatically the active destination.

## Keep scope and modularity clear

Record separate feature milestones independently. An optional integration must not become a hidden prerequisite for unrelated work merely because one agent implemented it that way. Check the owning project's actual dependency/disabled-feature tests before reporting that the coupling is fixed; an architectural aspiration is not proof.

Engineering-Atlas and Feature-Foundry feed native Athena integration. Do not create new independent legacy maintenance tasks. Source deletion readiness requires reconciled capabilities, history, links, tests and remaining dependencies; distinguish readiness for each source and never infer deletion authorization from this index.

## Make a minimal public update

Update the relevant existing item rather than appending a duplicate running narrative. Preserve owner-authored accountability, explicit pauses, source provenance and unrelated text. Link source/test receipts in the owning repository instead of copying code or raw logs into this index. Public project status must not include private paths, account details, benefits/health data, credentials, private transcripts or unlicensed artifacts.

Check that links resolve to the intended project and revision; do not make a private resource public to satisfy a link check. Mark completion only for the exact verified gate. At closeout record the remote commit and check current published text. An instruction to continue the backlog is not a claim of uninterrupted execution or permission to expand the task.
